# Écran 8 — Moi

**Rôle** : savoir où est gardé son carnet, choisir son pseudo, récupérer ses données, supprimer son compte, se déconnecter.

Route : `/me`.

## Hiérarchie

1. Titre serif « Moi ».
2. **Ton carnet** : état de la session.
   - Session anonyme : « Ton carnet n'est gardé que sur cet appareil. » + bouton « Le garder sur tous mes appareils » (→ `/sign-in`). Mention : « Sans compte, un carnet inutilisé pendant 30 jours est effacé. »
   - Compte : « Ton adresse : {email} ».
   - Aucune session : « Ton carnet n'existe pas encore. Il apparaîtra avec ta première envie. » + « J'ai déjà un carnet » (→ `/sign-in`).
3. **Pseudo** : champ texte, sauvegarde automatique, `SaveIndicator`.
4. **Tes données** (phase 5) :
   - « Télécharger mes données » (compte seulement ; sinon une phrase explique que l'export viendra avec l'adresse) → `GET /api/export`, archive ZIP : `elan-export.json` complet, `envies/*.md` lisibles, `images/` originales, `LISEZ-MOI.txt`.
   - « Supprimer mon compte » (bouton discret, ouvre une feuille) : rappel d'exporter avant, saisie du mot « supprimer », bouton destructeur (seul usage du rouge). `DELETE /api/account` efface images puis compte (cascade SQL), vide les caches du service worker et le stockage local, puis affiche un message de remerciement et « Revenir à l'accueil ». En cas d'échec : « Rien n'a été effacé », on peut réessayer.
5. **Se déconnecter** (bouton secondaire, absent pour une session anonyme : on n'y perdrait que son carnet).
6. Liens : Politique de confidentialité.
